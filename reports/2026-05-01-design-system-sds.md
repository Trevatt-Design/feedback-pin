## Brief (verbatim from the user)

> Update the entire GUI to match this figma library:
> https://www.figma.com/community/file/1380235722331273046 look for the
> open source codebase first and use that to refractor everything. Do

The Figma library is **Simple Design System (SDS)** by Figma; open
source at https://github.com/figma/sds (MIT).

## Plan summary (from Stage 2)

Adopt SDS as the canonical UI vocabulary across feedback-pin. Vendor
upstream `figma/sds` at commit `be440d804c525a0d5654900161988edbe9754575`
into `dashboard/web/src/sds/` (MIT licence preserved verbatim, provenance
recorded). Rebuild the dashboard as a Vite SPA + slim Cloudflare Worker
serving Workers Static Assets, dropping the prior esm.sh CDN
architecture. Consume SDS primitives directly in dashboard routes
(`CommentsList.tsx`, `CommentDetail.tsx`, `Login.tsx`) and components.
For the widget — which must stay vanilla TypeScript inside a shadow
root — consume SDS at the **token** level via `widget/src/tokens.ts`
(every selector rewritten to `:host`). Per-surface deviations remain
custom by design (cursor badge geometry, outline-only highlight,
spotlight overlay opacity, submit-button radius) but consume SDS
colour/radius tokens. Bundle budget enforced; CSP branched per-route
(strict on SPA, relaxed on `/review`).

Plan file: `/Users/Administrator/.claude/plans/update-the-entire-gui-bubbly-nest.md`.
