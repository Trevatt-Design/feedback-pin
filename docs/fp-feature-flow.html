fp-feature pipeline

Skill
Agent
Inline
Hand back
Loop
Artifact
▶ Trigger — user brief trigger

Any request that adds, changes, or removes functionality.

0 Pre-flight — load project context inline
Reads
  • manifest.yaml
  • decisions.log
  • PLAN.md · PLAN-v2.md
1 Brief intake skill: shape

Restate need, identify surfaces, list edge cases, surface open questions.

Gate
  • Blocking gaps → HAND BACK
2 Conflict scan inline

List existing contracts that change, anti-features the brief might violate, invariants that must be preserved.

Output
  • Short plan: contracts to change + new contracts to add
Gate
  • Anti-feature triggered → HAND BACK
Stage 3 — specialist review (parallel)

security-review skill

Auth gates, input validation, data leakage, dependency risk, secrets handling.

audit skill

a11y, performance, responsive.

adapt skill

Browser / device / viewport compatibility, iframe context, CORS.

critique skill

UX coherence, copy clarity, audience fit.

Gate
  • Blocking findings → revise plan, re-run stage 3
  • Non-blocking → engineer constraints
4 Implementation — engineer agent

Write code only. Apply verify-before-fix for any change to existing behaviour.

Tools
  • Read · Edit · Write · Bash · Grep · Glob
Writes
  • widget/src/**
  • api/src/**
  • dashboard/src/**
Runs
  • npx tsc --noEmit
Refuses
  • Edits to manifest.yaml
  • Edits to test files
  • Anti-features
5 Tests — test agent

Mirror every contract, cover every invariant, cover unhappy paths.

Writes
  • tests/unit/** — Vitest
  • tests/api/** — Vitest + miniflare
  • tests/e2e/** — Playwright
Runs
  • npm test — must be green
Gate
  • Suite red → back to engineer
Stage 6 — quality pass (parallel)

simplify skill

Reuse, dead code, repeated patterns.

harden skill

Production-grade error states, edge cases, empty states.

7 Integrator agent

Final accounting. Cannot edit code or tests.

Writes / appends
  • manifest.yaml
  • decisions.log
  • reports/<YYYY-MM-DD>-<feature-id>.md
Runs
  • Full test suite (final gate)
  • Drift check
  • Preview deploy if configured
8 Final review skill: review

Last gate before user hand-back.

9 Hand back to user hand back
Returns
  • Summary + verification report
  • Preview URL if available
